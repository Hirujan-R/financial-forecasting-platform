# Volatility Regime Prediction Model

[![Powered by Kedro](https://img.shields.io/badge/powered_by-kedro-ffc900?logo=kedro)](https://kedro.org)

An end-to-end machine learning system for predicting future volatility regimes across major technology equities using historical market data.

The project builds a binary classification model that predicts whether an asset is likely to transition into a **higher volatility regime** or remain in a **lower volatility regime**.

The pipeline combines financial feature engineering, machine learning modelling, and MLOps practices to create a reproducible workflow.

Built using:

- **Kedro** - modular and reproducible ML pipelines
- **DVC** - dataset and pipeline version control
- **MLflow** - experiment tracking and model management

---

# Problem Definition

Financial markets are characterised by changing volatility regimes. Periods of low volatility can transition into periods of increased uncertainty, larger price movements, and elevated risk.

The goal of this project is to predict future volatility regime changes for individual equities:

- Alphabet (**GOOG**)
- Apple (**AAPL**)
- Microsoft (**MSFT**)
- NVIDIA (**NVDA**)

The model performs binary classification:

| Target | Description |
|---|---|
| `1` | Future volatility expansion |
| `0` | Volatility contraction / stable volatility |

The target is generated by comparing future realised volatility against historical volatility conditions.

Future realised volatility is estimated using the **Garman-Klass volatility estimator**:

\[
\sigma^2_{GK}
=
0.5(\ln(H/L))^2
-
(2\ln(2)-1)(\ln(C/O))^2
\]

A volatility expansion event occurs when:

\[
Future\ Volatility > Historical\ Volatility
\]
